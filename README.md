🐰 Project Tiny Bunny — Визуальный новелла-проект
Project Tiny Bunny — это одностраничное веб-приложение в жанре визуальной новеллы (Visual Novel), вдохновлённое атмосферными сюжетами с элементами хоррора и интерактивного повествования. Проект реализован с акцентом на нарастание напряжения, мультимедийную подачу и плавное взаимодействие с пользователем через нажатия и триггеры событий.

🧩 Функциональность и особенности:
Интерактивное повествование: история разворачивается по мере нажатия пользователем, реплики появляются последовательно

Смена сцен и персонажей: использование визуальных переключений, плавных переходов между фонами, персонажами и диалогами

Мультимедийное сопровождение: включение звуковых эффектов и/или фоновой музыки (если реализовано), что усиливает атмосферу

Лёгкие анимации появления текста: добавляет «живости» и вовлекает в процесс

Адаптивность интерфейса: проект адаптирован под различные экраны (если реализовано)

Переходы и контроль: кнопки "продолжить", управление сценами, возможный переход к новым эпизодам

⚙️ Технологии и стек:
🔧 Frontend:
React.js – компонентный подход, управление состоянием, рендеринг сцен без перезагрузки

React Hooks – useState, useEffect и другие хуки для работы с логикой смены сцен, диалогов, таймеров

React Router (если есть навигация) – возможная реализация перехода между сценами, эпизодами, меню

🎨 UI и анимации:
CSS Modules / Styled-components / SCSS – стилизация компонентов

CSS-анимации / keyframes – эффект появления текста, плавные переходы сцен

Flexbox / Grid Layouts – выравнивание элементов, панелей диалога, фонов

Фоновое изображение + персонажи – работа с z-index для наложения

📦 Инфраструктура и деплой:
Vercel – быстрая сборка и деплой React-приложения

GitHub – отслеживание версий и организация командной работы (если применимо)

📚 Архитектурные и проектные решения:
Чистая структура компонентов – отдельные блоки для сцен, диалогов, интерфейсов

Менеджмент истории и диалогов – возможно использование конфигурационного JSON или объекта с логикой сюжета

Принцип декларативного UI – визуальные состояния сцены определяются текущим состоянием приложения

Проект ориентирован на расширяемость – легко масштабировать сюжет, добавлять новые сцены и развилки

🛠 Потенциал для доработки и масштабирования:
Создание системы сохранения и загрузки прогресса

Добавление ветвления сюжета (выборов и последствий)

Реализация озвучки персонажей

Внедрение локализации на несколько языков

Добавление настроек звука, скорости текста и оформления

Переход в формат PWA для запуска на мобильных устройствах
